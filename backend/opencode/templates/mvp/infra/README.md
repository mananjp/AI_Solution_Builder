## Quick start (local)

```bash
docker-compose -f infra/docker-compose.yml up --build
```

- Backend: http://localhost:8000/docs
- Frontend: http://localhost:3000

Or run services individually:

```bash
# backend
cd backend
cp .env.example .env      # then fill values
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

# frontend
cd frontend
cp .env.example .env.local
npm install
npm run dev
```

## Deploying to Render (one click)

1. Push `main` to a GitHub repo.
2. Contrast GitHub → Render via [render.com](https://render.com): connect the repo,
   choose **Blueprint**, select `infra/render.yaml`.
3. Render creates PostgreSQL + backend + frontend automatically.
4. GitHub Action CI runs lint/test/build on every push; when it is green
   on `main`, Render auto-deploys the new commit.
